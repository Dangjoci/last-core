# LAST CORE

HTML5 zombie survival defense. Family holds a CORE in a ruined winter plaza.

**Play:** https://dangjoci.github.io/last-core/

This is the hackathon entry build. The original live game remains at https://dangjoci.github.io/zombie-defence/

## 플레이
세로 모드. 왼쪽 조이스틱(모바일) / WASD(PC). 자동 공격. 건설·연구·구조.

- Android Chrome: 메뉴 → 앱 설치
- iPhone Safari: 공유 → 홈 화면에 추가

## Stack
Single `index.html` canvas PWA + GitHub Pages. No backend.
